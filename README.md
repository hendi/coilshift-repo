# hendi CoilShift repository

Public package repository for CoilShift.

Packages currently published:

- `dev.hendi.startlogo` 0.1.0
- `com.hendi.todo-card` 0.1.0

The repository root is generated with `csdk repo build`. Add the GitHub Pages URL of this repository to CoilShift; `index.json` and every archive under `pool/` must be served unchanged over public HTTPS.
